# 特雷森填字室

**简体中文** · [English](README.en.md) · [日本語](README.ja.md)

以《赛马娘》角色名为答案的随机填字游戏。原生 HTML、CSS 与 JavaScript ES Modules 实现前端；JSON 维护角色和多语言提示；可选的 Cloudflare Worker + D1 统计服务通过同域 API 接入。

## 功能与规则

- 四类题组：入门级、进阶级、二つ名、芦毛灰姑娘。每局抽取角色、生成交叉棋盘，再随机选择提示，不再选择固定子关卡。
- 界面及提示支持简体中文、英语、日语；填答文字独立选择英字或片假名。
- 大棋盘横竖各 10 题，小棋盘各 6 题；电脑默认大棋盘、手机默认小棋盘，可手动改选。棋盘支持横向拖动及格子缩放。
- 辅助模式整词答对后标绿、显示三语名字，查询与查看当前答案不限次数。挑战模式隐藏未揭示答案的正确性，每局查询 3 次、揭示 3 道不同题；揭示后自动填入、标绿、锁定。
- 两种模式均可提前结束并公布答案；单题帮助和设置窗口不暂停计时。只切换界面语言或模式保留状态，应用不同题组、文字、尺寸或重新随机开局才重置。
- 本地导出 PNG：空白棋盘、当前输入，以及结束后可用的答案版。提示使用当前界面语言；时间与状态可选。图中带游戏网址与二维码，方便打印。
- 主界面与结束弹窗提供 GitHub Issue 和邮件提示词投稿入口。
- 统计按题组 × 尺寸分成八组，只显示开始局数、成功通关数和平均成功用时，英字和片假名合并。统计的是匿名游戏局数，不是去重人数。

## 本地开发

使用 Node.js 24。无需安装 npm 依赖；二维码编码器以保留 MIT 许可的源码随项目分发。浏览器需支持模块、Fetch、Web Worker、Canvas 和原生 dialog，通过 HTTP 打开页面。


| 命令 | 用途 |
| --- | --- |
| npm run dev | 源码预览，默认 http://localhost:5173/ |
| npm run check:data | 校验角色、随机提示库及历史题库 |
| npm test | 游戏规则、随机棋盘、三语文案、统计与真实 SQLite 回归测试 |
| npm run benchmark | 测量四题组 × 两文字 × 两尺寸的生成速度 |
| npm run build:worker | 生成服务端角色候选池和旧版本兼容数据，需提交生成文件 |
| npm run build | 校验数据，重新生成 dist/ 静态产物；不自动运行测试 |
| npm run preview | 从 dist/ 预览，需要先构建 |

Windows PowerShell 可使用 npm.cmd。开发与产物预览共用默认端口，同时运行时设置不同 PORT。

## 代码框架

| 模块 | 职责 |
| --- | --- |
| index.html、src/style.css | 页面、滑块、图标选项、弹窗和响应式样式 |
| src/main.js | DOM、输入法与粘贴、焦点、设置及会话编排 |
| src/game.js | 无 DOM 的会话状态、计时、模式、配额、判定、搜索与棋盘校验 |
| src/catalog.js、src/clue-bank.js | 加载及校验当前角色和提示库 |
| src/generator.js、src/generator-worker.js | 有界随机重启排盘与后台线程入口 |
| src/i18n.js、src/random-i18n.js | 三语界面文案和插值 |
| src/export.js、src/vendor/ | Canvas PNG 导出与离线二维码 |
| data/characters.json、data/clues.json | 标准名字、别名、按角色与题组管理的三语提示及来源 |
| src/analytics.js、src/random-protocol.js | 匿名统计队列、缓存、上报与盘面摘要协议 |
| functions/api/ | Pages 同域 API，经 STATS 绑定转发 Worker |
| worker/ | 新随机统计 API、旧 API 兼容、D1 迁移与生成候选池 |
| scripts/、tests/、schemas/ | 构建、基准、维护校验与回归测试 |

GameSession 不依赖 DOM，时钟可以注入。completed 表示本局结束；成功必须检查 finishReason === 'solved'，'revealed' 表示提前结束。刷新后不恢复盘面；界面语言及每位角色近期提示 ID 保存在本机。

生成器先不放回抽样，再通过合法交叉、相邻约束、方向配额、紧凑度评分和有限重试生成连通棋盘。小／大盘最大边长为 30／40 格，实际尺寸由名字决定。后台生成避免阻塞输入；按钮显示忙碌状态，等待超过 400ms 显示排盘提示。800 次开发机基准全部成功，分组平均约 3–19ms；此数据不代表手机端耗时，详见报告。

## 题库维护

当前提示库覆盖 97 位角色、275 条三语记录。普通和剧情角色提供多条提示；二つ名保持来源中的真实称号，有两种称号时同时展示，不编造称号变体。入门和进阶可共享角色，但提示按题组范围与维度权重抽取。

新增内容时维护 characters.json 和 clues.json，保持稳定 characterId 与提示 id。每条提示补齐 zh-CN、en、ja、适用题组、维度、来源，人工核对事实与对应唯一性。避免把笼统性格描述当作独立线索。

英文名去空格、标点并大写；片假名保留小假名和长音，每字符一格。剧情原创角色沿用作品名字，不替换为原型马名。现有八套固定棋盘只保留为历史资料及测试夹具，运行时不再加载。

题库改动后执行 check:data、build:worker、test、build，并提交 worker/pool.generated.js 及需要变化的 worker/levels.generated.js。不要手动编辑生成文件，也不要提交 dist/、凭据或本机数据库。

## 统计与升级

新接口为 /api/v2/；按题组和尺寸汇总，不按随机种子或棋盘版本分组。开始时校验合法棋盘并仅保存标准答案哈希，成功时核对盘面；不在数据库保存 IP、查询词或答案明细。随机 runId 用于去重，失败上报会在本机临时排队重试。统计故障不阻塞游戏，本地与预览默认不写生产库。

v0.7 升级需执行新增的 0002_random_stats.sql 迁移，再发布 Worker，最后发布前端。旧表与旧接口保留供历史及旧客户端使用，旧固定盘数据不混入新随机盘统计。不要只推送前端而遗漏 Worker 与数据库升级。
